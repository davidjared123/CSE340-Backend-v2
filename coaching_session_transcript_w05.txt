Ahora pasemos al tercer tema: **Middleware de Acceso Protegido**.

En tu archivo [users.js (controlador)](file:///Users/davidperez/Documents/BYU/CSE340-Backend-v2/src/controllers/users.js#L85-L95), implementaste el middleware `requireLogin`:

```javascript
export const requireLogin = (req, res, next) => {
    if (!req.session || !req.session.user) {
        req.flash('error', 'You must be logged in to access that page.');
        return res.redirect('/login');
    }
    next();
};
```

David: es como dice ya termine de validarr con exito next()

Coach: ¡Exacto! `next()` le dice a Express que este middleware terminó su trabajo con éxito y que puede continuar al siguiente middleware o a la función que maneja la ruta. Si se te olvidara incluir `next()`, la petición del usuario se quedaría colgada en el navegador (cargando indefinidamente) sin recibir ninguna respuesta.
